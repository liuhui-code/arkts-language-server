## Changes and invariants

- ScopeModuleBindings and ScopeSourceBoundaries now retain cache owners through
  actual node reference transitions. Duplicate binding requests in one node acquire
  once. SDK-name retention follows live binding owners. Old source/binding owners
  release on node replacement/removal; uncommitted drafts are pruned in finally,
  including cancellation/error. These are metadata cache references, NOT compiler
  DocumentRegistry AST leases or Native process/SQLite resource leases.
- replaceNode finishes cancellable edge normalization before reference/adjacency/
  seed/node commit. Old/new ownership is prevalidated before mutation. No IO or
  cancellation point is introduced halfway through this reference transition.
- Mandatory current proof validation also collects stale node/boundary consumers.
  Same immutable role snapshot may repair those actual stale project consumers;
  final validation remains independent and no cross-request valid bit is stored.
- Completed SourceFact passes supply an issued, frozen ScopeRoleDelta receipt:
  exact before/after immutable producer map identities and copied existing-source
  paths. It is lineage/coverage attestation from that private producer, NOT disk
  freshness or permission to skip source,SDK/config or final observations.
- Role changes seed dirty nodes even when physical metadata proofs remain current
  (e.g. actual overlay edits). Project-only edge changes update existing reverse
  edges/seeds and recompute effects when topology changes. No new canonical role
  directory or whole-pass owner-used marking is needed for these local updates.
- Changed external/SDK reachability, unknown/missing lineage, source membership
  creation/removal,alias/config uncertainty and incomplete/cancelled reconciliation
  retain full fallback. Old code is not bypassed to emit incomplete success.
  SDK/new unknown target closure is not declared locally repaired.

Source roles remain producer-owned immutable snapshots; the graph never mutates
those maps. A receipt is issued only after a complete known fact pass. Missing or
noncontiguous history retains full rebuild. Current/final metadata may detect
silent changes independently of events. Original failed witnesses are not reset,
re-stamped or removed from an active request's final union to make it pass.
