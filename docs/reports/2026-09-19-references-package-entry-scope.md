# References package-entry scope correctness gate

Date: 2026-09-19

## Result

The restored real Photos workspace exposed a false complete identity proof.
Legacy `textDocument/references` returned 17 `EditorController` Locations;
the default-off identity-batched experiment returned only nine. The omitted
Locations were the root-level `browserCommonPhone/index.ets` re-export and its
package-root consumers. The package manifest declares `main: "index.ets"`,
while ProjectGraph source roots start under `src/main`.

The index had cataloged the package entry and uniquely resolved consumers to
it, but the scoped proof omitted the entry from admission and classified that
source as disjoint. Rust memory and SQLite now fail closed if an in-scope
binding points to a catalog-owned source outside admission. The worker also
admits the validated package entry as one exact file; it does not broaden the
scope to the whole module directory.

## Reproduce

Use the exact checkout and SDK above, build the server and release sidecar,
then run:

```bash
node scripts/bench/replay-references.mjs \
  --workspace /private/tmp/applications_photos-6.1-lts \
  --sdk /Applications/DevEco-Studio.app/Contents/sdk/default/openharmony \
  --file browserCommonPhone/src/main/ets/controller/EditorController.ets \
  --symbol EditorController --line 133 --character 14 \
  --oracle /private/tmp/photos-editorcontroller-legacy-pass2.json \
  --out /private/tmp/photos-editorcontroller-identity-package-entry.json \
  --mode A --strategy indexed-batched --sdk-profile common \
  --dependency-profile identity --batch-roots 1 --trace --idle-ms 0 \
  --timeout-ms 180000 --diagnostic-timeout-ms 180000
```

The oracle was generated by a separate legacy replay on the same checkout.
The compact [machine-readable evidence](evidence/2026-09-19-references-package-entry-scope.json)
records the run values; raw curves remain in the local `/private/tmp` reports.
