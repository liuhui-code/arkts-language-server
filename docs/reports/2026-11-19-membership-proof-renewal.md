## Mechanism and safeguards

`CompleteMembershipProof.renew` accepts only complete identical member paths,
identical token keys, and an exhaustive list of admitted existing changed paths.
Every untouched token must equal its original fact; unknown keys, missing tokens,
partial status or an already-invalid proof cannot renew. Metadata checks are
cancellable; they create no new authority until complete.

A successful replacement retires the old proof permanently and creates a distinct
owner with original unchanged tokens plus the explicitly admitted changed tokens.
Names, original namespace/configuration witnesses and overlay-only obligations are
preserved. A Map copy is used instead of another journal/persistent collection.
New proof `current` still observes every file raw plus the namespace/scope on both
sides; its independent final union still runs. Neither a watch notification nor
renewed metadata is cached disk validity. New source bytes still use the normal
admitted read's descriptor/identity guards.

Only the existing compatibleDiskDelta branch in workspaceFilesChanged may request
renewal: accepted known existing non-overlay body changes, no rejected source
changes. Creates/deletes, ineligible/unavailable changes or unexplained token/namespace
changes cannot borrow old authority and fall back to original full discovery.
Stable already-proven root aliases retain the original physical directory witness;
a semantic-engine reset alone is not proof that the physical member set changed. No renew API on an older/injected producer
also falls back. A concurrent unnotified sibling or root/configuration change is
caught by the retained raw proof and returns to normal invalidation/reconciliation.
Old requests cannot acquire the replacement owner even if bytes are later undone.

This does not remove full file checks or claim end-to-end scale independence.
There are no new Programs/ASTs. Shared original names/namespaces are immutable;
old token generations remain referenced only by actual retained consumers until
normal lifecycle release, as with existing full replacements. Endurance still has
to verify retained resource trends.
