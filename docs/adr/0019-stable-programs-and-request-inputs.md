# ADR 0019：稳定语义组、长期 Program 与请求输入复用

- 日期：2026-10-19。
- 状态：Accepted，维护者已授权实现与对比测试；实现和性能验收 **IN_PROGRESS**。
- 父版本：`3add697043380612efe71cef074e5de292422fe2`。
- 执行与逐片证据：[实施记录](../tdd/stable-program-optimization.md)。
- 基线：[Mac Photos 规模诊断](../reports/2026-10-19-mac-photos-scaling.md)。

## 原因

默认 member 补全仍使用整个 workspace Program；degraded / edited references
可能绕过驻留 owner，逐批创建 LS。SDK AST 已共享，但读取、路径见证和
共同项目依赖仍有重复。固定两个交互上下文和一个扫描槽还会在预算充足时
驱逐可复用状态。扩大批次本身不能解决这些生命周期和输入证明问题。

## 决定

1. 使用真实 workspace/product/module/target、编译选项和 SDK/compiler
   兼容身份定义稳定语义组。内容、光标、候选和打开数量不改变组 ID。
   图与成员版本维护组根和依赖闭包；未知边界保留完整安全范围。
2. 沿用现有语义 owner、Host、DocumentRegistry 和 coordinator。每组保留
   LS；Program 可随编辑换代，合法未变 SourceFile 和解析事实持续复用。
   请求借用并归还 lease，不在每次请求后销毁组。
3. 重型编译任务保持串行；驻留数量主要由统一压力决定，取代 ADR 0018 的
   固定两组加一个扫描槽限制。后台扫描不提升交互近期性。无固定空闲 TTL；
   压力优先回收空闲扫描状态，再按交互 LRU 回收其他无 lease 上下文。
4. 保留可配置默认 4096MiB 和现有压力阈值、滞回。首次初始化主动在实际
   查询 isolate 准备共享 SDK/标准库及当前选定product/target内所有已确定的组；
   已打开文件所属组优先，其余串行准备，不取排序后的固定前两组。预解析不扩大 ambient
   根。首次准备完成（含 degraded）即消费豁免，普通恢复不能再次豁免。
   运行期观测构建峰值、整个进程树 RSS，Node Worker 不重复计 PID RSS。
5. 默认交互能力接入合法稳定组。编辑和 close/reopen 更新文本权威及版本；
   完整相关 delta 更新原 LS，配置不兼容才退役旧域。变更不明保守重建。
6. 引用在索引候选/锚点准备之前，优先同步已实际准备且能覆盖合法范围的
   驻留 owner；否则逐组搜索。只检查是否能复用不得隐式创建冷owner。
   degraded不等同于必须重建，具体查询仍独立证明可用性。每组证明自己
   的搜索范围，合并证明全部必查范围已覆盖。索引只提供候选，官方编译器
   保持最终权威。别名、继承、ambient、overlay 及跨组输入不得被省略。
7. 一个请求共享已固定的文本、SDK 快照、解析结果及正负路径见证。各组
   消费同一输入记录；发布前核验联合输入。输入变化撤销发布资格，不以
   watcher 必达、旧 stat 或 AST 缓存命中代替当前输入证明。
8. 仅保守回退使用 **1024 个候选根软目标**；保留原配置名，初版支持
   1–2048。依赖闭包及压力可降低批次；完整语义单元可超过目标。根数量
   不代表 Program 总文件数或内存上限，不能把一个真实模块改成伪项目。
9. 正常路径优先统一 owner。迁移中保留隔离 verifier 的完整安全控制路径，
   必须记录触发原因、准备成本和覆盖，不将控制路径冒充已取得复用收益。

### 2026-10-21 自审后的实施约束

- 工作区事件消费、组的编译输入版本和单文件版本分别维护。连续 delta 已被
  消费，不代表每个组的 Host project version 必须变化。仅当能覆盖实际 compiler
  输入及组根时才可排除无关编辑；未知、负解析恢复、ambient、成员及配置变化
  保持保守处理，不能只以 `semanticRootPaths` 代表实际依赖。
  已见证编辑对单文件版本和旧文本/映射的失效不得被组筛选丢弃：当前无关的
  文件可能成为未来依赖，首次加载及冷 owner 也不能碰撞共享 Registry 的旧版本。
- Registry 接受一个 snapshot 参数不代表它接管该对象。固定编译器同文件同
  版本可返回原 SourceFile 并保留原 snapshot；复用记录必须关联实际返回对象，
  保留原文本映射、准入身份和当前/独立终检。共享语法不共享 owner 的语义资格。
- 请求阶段正身份复用按保留字符串及条目开销记账；本轮候选采用 32MiB 记账
  预算，溢出正常读取。查询阶段与最终联合核验分别清空并重新获取，不跨请求
  保存，不替代读前/读后守卫。此数值是临时 metadata 预算，不是 RSS 硬上限。
- 完整成员目录、各组合法编译输入、本次查询必查范围为不同集合。逐组引用
  必须证明目标语义身份相容、合法上下文、必查覆盖/排除和同一输入代次；
  位置结果的并集不具备这些资格。ADR 0005 的局部并集禁令继续适用，只有通过
  真实 LSP 等价回归的新证明路径才能迁移。rename 还须保留官方 rename 语义。
- 根 READY、磁盘答案缓存和完整控制路径在各自消费者完成等价迁移前保留。
  不以组 READY 布尔值相与代替输入身份、代次、能力及覆盖证明。单模块 20k
  与多模块 20k 分开验证；不能只靠模块隔离宣称组内更新成本已解决。

本轮实现、失败反馈和检查见
[2026-10-21 输入所有权实施记录](../tdd/incremental-input-ownership-20261021.md)。

## 替代与保留

- 明确修订 ADR 0018 的固定驻留容量，以及 degraded 后可能重复首次准备的
  实现边界。保留初次压力豁免、500ms、共享 SDK、完整作用域和延迟释放。
- 修订 ADR 0003/0016/0017 的逐 job 项目释放，仅限已迁移并验证的新路径。
  未迁移控制路径继续原规则。SDK 与项目所有权分别观测。
- 保留 ADR 0004/0005 的完整答案与索引信任边界、取消和发布围栏。
- 不重启已暂停的 S02 语义事实索引研究，不更换官方编译器，不增加第二套
  文档权威。引用完整性失败不能以空或部分结果代替。

## 实施与验收

逐片使用真实子进程 Content-Length stdio RED→GREEN，记录命令和父版本。
先修初始化/驻留，再接交互和引用，随后共享输入和回退；每片覆盖对应
新鲜度、取消、配置及压力反例。手写新文件最多 500 行，修改超限旧文件
不增行并提取内聚职责。最终执行当前实现的 `pnpm check:fast`。

冻结旧 runtime、SDK、夹具、查询目标和运行模式，使用隔离 Photos 副本及
递增规模串行前后对照，每规模至少三个独立进程。分别报告 READY/degraded、
冷启动/首次/重复/编辑/关闭重开/压力恢复；正常计时与带观察探针运行分开。
保留逐次请求结果、LS/Program/解析计数、候选/批次、输入读取和阶段时间、
内存及输入哈希。共享状态和响应正确不等于收益；负收益和失败保留。

完整响应 **每次 500ms** 为目标，watchdog 不作为验收。首次准备单列，
查询等待与恢复不豁免；大范围搜索仍有工作量下界。尚未测试的范围不能
宣称完成，ADR/ledger 的实现、功能回归、性能和资源结论分别记录。

### 2026-10-21 输入所有权与组版本候选（非完成资格）

本轮P0绑定Registry实际返回的SourceFile/snapshot，区分事件消费、组compiler输入
与单文件版本；正身份metadata改为32MiB同步phase预算，独立终检仍重新获取。
随后v2仅对旧import提取regex去掉最后引号之后的不可能匹配后缀，保持capture语义，
