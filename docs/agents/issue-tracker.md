# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues. Use the `gh` CLI
for all operations and infer `liuhui-code/arkts-language-server` from the
repository remote.

## Conventions

- Create an issue with `gh issue create --title "..." --body "..."`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- List issues with `gh issue list` and request JSON fields when a skill needs
  structured filtering.
- Comment with `gh issue comment <number> --body "..."`.
- Apply or remove labels with `gh issue edit`.
- Close resolved or rejected issues with `gh issue close` and a concise
  explanatory comment.

When a skill says to publish to the issue tracker, create a GitHub issue.
When it says to fetch the relevant ticket, read the GitHub issue including
comments and labels.
